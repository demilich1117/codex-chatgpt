# Codex / ChatGPT · 酒馆界面

为 SillyTavern 制作的独立界面扩展与配套主题。桌面采用 Codex 风格的分栏导航，手机采用 ChatGPT 风格的会话页与推页侧栏。

当前配套扩展版本 **0.1.5**，配套主题沿用 **0.1.3**。本项目并非 OpenAI 官方客户端；名称用于说明界面设计参考。

## 0.1.5 侧栏管理与抽屉宽度

桌面条目上直接提供置顶、归档快捷图标，删除放在“…”更多菜单；手机只保留“…”入口，在菜单里置顶、归档和删除，避免误触。角色、群聊和当前角色/群聊的聊天可置顶、归档与恢复。归档仅改变本扩展侧栏分组，不删除原生文件，也不改变原生收藏。

删除聊天和角色保留原生确认；删除角色默认保留聊天，勾选后才同时删除全部聊天。正常路径不刷新整页；删除当前聊天会加载剩余聊天，角色删除返回原生空闲状态。群聊本身的删除继续从原生群聊管理进入。

桌面右侧抽屉默认 **760px**，可拖动左边缘在 **480–1100px** 内调宽并记住选择；实际宽度受屏幕可用空间限制。双击边缘恢复默认，聚焦边缘后可用方向键微调、Home/End 到达边界。手机保持整页抽屉。

更新扩展文件后刷新一次即可载入本轮代码，已有 0.1.x 配套主题无需重新导入。详见 [验证记录](docs/validation-0.1.5.md) 与 [整套抽屉重构方案](docs/drawer-redesign-proposal.md)。0.1.5 通过仓库默认分支提供，可在酒馆扩展管理中检查更新、更新本扩展，然后刷新页面。

## 0.1.4 主题联动

配套界面只在当前实际使用 Codex / ChatGPT 美化时启动。切换到其他主题后自动移除侧栏、页头、外观面板与活动提示，切回后恢复；无需刷新。手动取消“启用界面”后保持关闭。现有 0.1.x 主题和保留原 CSS 的重命名副本可直接使用，无需重新导入主题。工作台预览也按当前预览的作品启停。

0.1.4 的主题联动修复已并入 0.1.5。下方手动安装压缩包仍是 0.1.3；通过仓库地址安装或原生扩展更新可获取 0.1.5。配套主题 JSON 仍用 0.1.3。

## 0.1.3 阅读与导航修复

阅读宽度与字号可在原生用户设置中调整；侧栏分组可折叠，默认显示最多 5 个置顶项和 5 条最近聊天；角色图标再次点击可收回抽屉。修复深色主题把透明前端变为白底的问题。

从 [v0.1.3 发行版](https://github.com/demilich1117/codex-chatgpt/releases/tag/v0.1.3) 下载手动安装包或独立主题 JSON。更新同名扩展后刷新，再导入并选择 **Codex — ChatGPT · 0.1.3**；扩展和已保存的主题 CSS 需要一起更新。

## 安装

1. 在酒馆中打开 **扩展 → 安装扩展**，粘贴本仓库地址：

   ```text
   https://github.com/demilich1117/codex-chatgpt
   ```

2. 安装后刷新酒馆。从 [最新发行版](https://github.com/demilich1117/codex-chatgpt/releases/latest) 下载 **Codex-ChatGPT-Theme-0.1.3.json**。
3. 打开 **用户设置 → UI 主题**，导入该 JSON，再手动选择 **Codex — ChatGPT · 0.1.3**。导入不会自动选中主题。
4. 在侧栏底部齿轮中选择深色、浅色、跟随系统和强调色。

主题与扩展配套使用。仓库根目录已包含可直接加载的扩展，无需用户构建，也不需要额外 Node 后端或在线字体服务。

### 手动安装

下载发行版的 `Codex-ChatGPT-0.1.3.zip`，解压后将 `codex-chatgpt` 整个文件夹放到 SillyTavern 的 `public/scripts/extensions/third-party/`，确保扩展目录内直接有 `manifest.json`。刷新后导入文件夹内的 `themes/Codex-ChatGPT.json` 并选择主题。该路径为桌面 SillyTavern 的全用户安装方式。

已手动安装到同名目录的用户可使用手动包更新；不要同时加载两份本扩展。

### 更新与恢复

通过仓库地址安装后，可在酒馆扩展管理中检查更新并更新本扩展，完成后刷新页面；版本应显示 0.1.5。0.1.5 沿用 0.1.3 主题，无需重新导入。以后只有配套主题本身变更时才需要重新导入 JSON。扩展不强制开启自动更新。

恢复原界面：直接选择其他 UI 主题，配套界面会自动关闭。若希望在 Codex / ChatGPT 美化下也停用界面，可在 **扩展 → Codex / ChatGPT → 启用界面** 取消勾选。

## 功能

- **双端布局**：桌面侧栏可收起、拖动调宽；手机侧栏打开时将聊天页推向右侧。没有 Chat/Work 切换。
- **角色与群聊**：快速切换、按名称搜索、置顶、归档、恢复、分组折叠；完整创建、导入和编辑功能仍在原生角色管理中。
- **聊天记录**：当前角色或群聊默认预览最近 5 份聊天，可展开全部、按名称筛选、置顶、归档、恢复和快捷删除；“管理当前聊天”打开原生完整聊天档案，可新建、重命名、导入、导出和删除。
- **完整原生分组**：回复配置、API 连接、回复格式、世界书、用户设置、背景、扩展、用户角色、角色管理。
- **外观**：深色、浅色、跟随系统，七种预设与自定义强调色；单聊可开关逐条头像与名字，群聊保留发言者身份。
- **推理与生成**：Thinking / Working 轻量扫光动画，根据原生状态显示；结束后保留原生推理记录和时长，支持减少动态效果。
- **原生消息操作**：保留 Markdown、媒体、编辑、复制、候选回复切换和推理折叠；候选箭头与计数独立成行。
- **切换保护**：侧栏导航会检查输入草稿、消息编辑与生成状态，避免误切聊天。

侧栏搜索目前按名称筛选，不提供消息全文搜索或跨角色聊天搜索。聊天置顶和归档按所属角色/群聊隔离；侧栏归档不是酒馆全局归档或备份。

## 兼容性与验证

已在 **SillyTavern 1.19.0** 的独立虚构测试环境验证桌面、手机视口、深浅色、九组原生面板、主题导入与保存刷新、编辑取消及已有候选回复切换。截图均来自虚构测试对话。

TauriTavern 以 **2.3.0** 的固定源码和浏览器视口契约为适配基线，**尚未验证真实 WebView、原生键盘和扩展安装流程**。Thinking / Working 已做受控状态复现，尚未调用真实模型验证流式生成。详细范围见 [兼容性记录](docs/compatibility.md)。

## 开发

Node.js 20.11+，无需安装构建依赖：

```sh
node scripts/build-public.mjs
node scripts/test-model.mjs
```

维护 `source/theme.css`、`source/theme-fields.json` 和 `source/extension/`。构建会将字体内嵌并更新根目录扩展文件及 `themes/Codex-ChatGPT.json`；请同时提交源码和生成文件。
